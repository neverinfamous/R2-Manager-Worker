# R2-Manager-Worker v3.5.9

## Highlights

- **Strict Origin & CSRF Protection**: Credentialed CORS headers and state-changing API requests now require same-origin or explicitly configured `ALLOWED_ORIGINS`.
- **Hardened Local Dev Detection**: Local authentication bypasses now verify request hostnames and reject header spoofing when production secrets are present.
- **Refreshed Dependencies & Container**: Updated runtime packages, GitHub Actions, and npm-bundled Docker layers to resolve upstream CVEs.

## Changed

- **deps**: Updated runtime and build tooling including `wrangler` (4.158.0), `vite` (8.3.6), `eslint` (10.14.0), `lucide-react` (1.70.0), and `jose` (6.2.16).
- **ci**: Upgraded pinned GitHub Actions (`codeql-action`, `docker/login-action`, `pnpm/action-setup`, and `trufflehog`) to their latest SHA digests.
- **config**: Disabled `workers_dev` and `preview_urls` by default in `wrangler.toml.example` and documented `ALLOWED_ORIGINS` across deployment guides.

## Fixed

- **auth**: Prevented forged `localhost` `Origin` headers from bypassing Cloudflare Access JWT validation and rate limiting in production.

## Security

- **cors**: Restricted `Access-Control-Allow-Origin` and `Access-Control-Allow-Credentials` to verified trusted origins and blocked untrusted cross-origin `POST`, `PUT`, `PATCH`, and `DELETE` requests with `403 Forbidden`.
- **docker**: Patched npm-bundled `glob` (14.0.4), `minimatch` (11.0.5), `ip-address` (10.7.6), and `postcss-selector-parser` (7.2.0) across builder and runtime stages.
- **deps**: Raised `undici`, `glob`, `minimatch`, and `ip-address` overrides in `package.json` to clear transitive advisories.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.5.9
```
