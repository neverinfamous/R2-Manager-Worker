# R2-Manager-Worker v2.0.0

## Highlights

- **Job History Tracking**: Track bulk operations with a complete audit trail and event timeline to monitor real-time progress.
- **AI Search Integration**: Connect R2 buckets to Cloudflare AI Search for powerful semantic search and AI-powered Q&A.
- **API Rate Limiting**: New tiered protection for API endpoints prevents abuse while ensuring fair resource access.

## Added

- **Job History Tracking**: New metadata tracking records operation events, error states, and bulk job execution details.
- **AI Search**: Capability to index compatible files and interact via dual search modes (AI-powered LLM and semantic retrieval).
- **API Rate Limiting**: Per-user enforcement for read, write, and delete operations to protect API endpoints.
- **Upload Integrity Verification**: Client-side MD5 calculation combined with server-side ETag verification prevents data corruption.
- **Strict TypeScript Compliance**: Enforced strict rules across the codebase, eliminating hundreds of linting warnings and potential errors.

## Changed

- **Database Architecture**: Introduced a new schema with specific tracking tables for job history events and records.

## Fixed

- **Workers.dev Persistence**: Enabled version-specific preview URLs and correctly configured subdomain persistence for stable test environments.
