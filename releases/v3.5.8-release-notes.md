# R2-Manager-Worker v3.5.8

## Highlights

- **Hardened Container**: The Docker image drops from 24 known vulnerabilities, including 2 critical, to a single unrated `musl` finding that awaits an upstream Alpine fix.
- **Fresh Stack**: React 19.3, Vite 8.3, Wrangler 4.156, and updated tooling keep the app current.
- **Safer View Preference**: A corrupted saved view setting now falls back to the list view instead of breaking the file grid.

## Changed

- **deps**: Updated all runtime and development dependencies and refreshed security overrides for `undici`, `ip-address`, `brace-expansion`, `picomatch`, and `flatted`.
- **ci**: Refreshed pinned GitHub Actions to their latest releases and pinned all runners to `ubuntu-24.04`.
- **docs**: Added GitHub and Docker Pulls badges to the README files.

## Fixed

- **filegrid**: Validate the saved view mode instead of casting it, so an invalid stored value no longer leaks into the UI state.

## Security

- **docker**: Patched `undici` and `postcss-selector-parser` bundled inside npm, and upgraded OpenSSL, zlib, and musl in the runtime image.
- **deps**: Raised `undici` to 7.30.1, clearing the open Dependabot alerts.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.5.8
```
