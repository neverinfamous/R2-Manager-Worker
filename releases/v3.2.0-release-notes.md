# R2-Manager-Worker v3.2.0

## Highlights

- **Health Dashboard**: Monitor system health scores, job failures, and low-activity buckets at a glance to ensure operational reliability.
- **Metrics Storage Tab**: Visualize storage distribution and object count trends over time to identify high-usage buckets instantly.
- **Expanded Webhook Events**: Track comprehensive file movement and folder operations with 6 newly added granular webhook triggers.
- **Auto-Detect Dev/Prod API**: Automatically switch API URLs during local development for a frictionless, zero-configuration developer experience.

## Added

- **AI Search Instance Status**: Real-time visibility into indexing jobs with historical sync tracking directly on instance cards.
- **Dynamic File Type Detection**: Live API integration to continuously sync supported file formats for AI Search compatibility.

## Changed

- **API Rate Limits**: Increased request thresholds by up to 300% to prevent rate-limiting during rapid UI navigation.
- **Support Contact Context**: Embedded support contact information centrally across all structured API error responses.
- **Dependency Updates**: Rolled out TypeScript, ESLint, and Wrangler upgrades to leverage the latest tooling optimizations.

## Fixed

- **Local Development Workflow**: Resolved cross-port API routing and signing key generation issues that previously blocked local testing.
- **AI Search Synchronization**: Corrected API parsing and routing errors to restore reliable instance listing and sync operations.
- **Security Scanning Alerts**: Fixed Docker Scout vulnerability parsing patterns to properly distinguish critical threats from false positives.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.2.0
```
