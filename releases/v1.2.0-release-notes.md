# R2-Manager-Worker v1.2.0

## Highlights

- **Cross-Bucket Search**: Find files anywhere in your R2 storage across all buckets from the main page.
- **Bulk Bucket Deletion**: Select and delete multiple buckets simultaneously with robust error handling.

## Added

- **Cross-Bucket Search**: Server-side parallel search across all buckets with real-time debouncing and sortable table results.
- **Advanced Filtering**: Filter by specific file extensions, size ranges, and upload dates.
- **Search Result Actions**: Download, copy, move, and delete files directly from search results.
- **Bulk Bucket Deletion**: Visual checkbox selection for buckets, progress tracking, and force delete functionality.

## Changed

- **Code Refactoring**: Extracted custom hooks to improve maintainability and testability.
- **Reduced Complexity**: File grid components simplified significantly while preserving all functionality.

## Fixed

- **File Transfer Path Logic**: Files now correctly default to root folder and path logic handles trailing slashes properly.
- **File Rename Operations**: Images reload with updated filenames and signed URLs, preventing stale data errors.
- **Context Menu Options**: Fixed TypeError when copying links from the right-click menu.
- **React Hook Pattern**: Fixed state update errors with rendering optimizations.
