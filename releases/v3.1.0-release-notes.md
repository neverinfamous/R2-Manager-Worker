# R2-Manager-Worker v3.1.0

## Highlights

- **Bucket Tagging**: Categorize buckets with custom tags and instantly locate them using powerful multi-tag search capabilities.
- **Bucket Color Tags**: Assign vibrant colors to buckets from a 27-color palette to enable quick visual identification of different environments.
- **Build Optimization**: Split vendor chunks and lazily load components to reduce the main bundle size by 30% for noticeably faster initial loads.

## Added

- **Search Navigation**: Dedicated search tabs for cross-bucket file searching and advanced tag filtering.
- **Automated Database Migrations**: Seamless schema upgrade detection to track and safely apply new database tables.

## Changed

- **Code Splitting**: Extracted vendor libraries (React, icons, utilities) into separate chunks for highly optimized browser caching.

## Fixed

- **WCAG Accessibility**: Improved keyboard navigation and added robust ARIA labels across the new tagging and color picker interfaces.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.1.0
```
