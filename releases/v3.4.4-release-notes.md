# R2 Bucket Manager v3.4.4

## Highlights

- **Security Update**: Patched a `tar` security vulnerability across npm and Docker layers to maintain strict security standards.
- **CI/CD Improvements**: Bumped Docker GitHub Actions to their latest major versions for improved build reliability.

## Changed

- **Dependencies**: Updated `@cloudflare/workers-types`, `@types/node`, `jose`, `typescript-eslint`, and `wrangler`.
- **GitHub Actions**: Updated `docker/setup-buildx-action`, `docker/login-action`, `docker/metadata-action`, and `docker/build-push-action` to their latest major versions.

## Security

- **tar**: Patched security vulnerability by overriding tar version 7.5.10 to 7.5.11 across npm and Docker layers.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.4.4
```
