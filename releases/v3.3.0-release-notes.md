# R2-Manager-Worker v3.3.0

## Highlights

- **Object Lifecycle Management**: Automate storage rules to transition objects to Infrequent Access or expire them entirely, generating immediate cost savings.
- **Rule Prefix Filtering**: Target granular object paths directly to apply lifecycle rules specifically to distinct directories like logs or temporary files.
- **CI/CD Pipeline Modernization**: Re-architected GitHub Actions into a 5-job pipeline featuring native ARM builds for significantly faster deployment.

## Added

- **Lifecycle Rules Panel**: Dedicated interface to view, create, toggle, and delete transition and expiration rules effortlessly.
- **Cloudflare API Integration**: Direct REST API integration for robust read-modify-write rule synchronization.

## Changed

- **Security Scanning Workflow**: Strengthened CodeQL policies to strictly block Docker builds upon detecting any security vulnerabilities.
- **Dependency Upgrades**: Updated critical ecosystem libraries including Workers Types, Vite, and Wrangler to maintain modern standards.

## Fixed

- **Code Scanning Alerts**: Remediated multiple CodeQL warnings by removing redundant null checks and unused variables across the codebase.

## Security

- **Strict Vulnerability Gates**: Blocked deployments systematically when severe code vulnerabilities are identified by CodeQL analysis.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.3.0
```
