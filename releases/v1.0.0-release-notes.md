# R2-Manager-Worker v1.0.0

## Highlights

- **First Official Release**: A self-hosted, feature-rich file management interface for Cloudflare R2 storage that provides capabilities missing from Cloudflare's native dashboard.

## Added

- **Bucket Management**: Create, rename, delete, and force delete buckets.
- **Folder Management**: Create, rename, copy, move, and delete folders with hierarchical navigation.
- **File Management**: Upload with drag-and-drop, chunked uploads, rename, copy, move, and batch operations.
- **Smart Filtering**: Basic search, type filters, and advanced extension, size, and date filters.
- **Download & Sharing**: Generate signed URLs and download multiple files as ZIP archives.
- **Modern UI**: Responsive interface built with React 19, supporting light/dark modes and grid/list views.
- **Enterprise Security**: GitHub SSO via Cloudflare Access, JWT validation, and HTTPS-only traffic.

## Security

- **HMAC-SHA256 Signatures**: Replaced weak XOR-based signatures with industry-standard HMAC-SHA256.
- **Zero Trust Architecture**: All requests authenticated by Cloudflare Access.
- **No Stored Credentials**: No user passwords stored anywhere.
