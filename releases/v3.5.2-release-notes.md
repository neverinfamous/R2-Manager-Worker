# R2-Manager-Worker v3.5.2

## Highlights

- **Production Stability**: Resolved React hook linting violations (`react-hooks/set-state-in-effect`) by batching state updates in `queueMicrotask`, preventing React Compiler memoization errors and ensuring stable dashboard rendering.
- **Security Validation**: Pinned `tar` to `7.5.13` in both npm overrides and Dockerfile to mitigate upstream vulnerabilities and protect the build environment.
- **Dependency Maintenance**: Updated multiple core packages including React, TypeScript, Vite, and ESLint to their latest versions to maintain ecosystem health.

## Changed

- **deps**: Bumped various npm dependencies including `react`, `lucide-react`, `vite`, `typescript`, `eslint`, and `wrangler` to keep the tech stack current.
- **deps**: Pinned `tar` to `7.5.13` in `package.json` overrides and `Dockerfile` to align with the latest secure version.

## Fixed

- **ui**: Remediated multiple `react-hooks/set-state-in-effect` violations across dashboard components by wrapping `setState` calls in `queueMicrotask`, avoiding synchronous re-renders.
- **codebase**: Removed unnecessary type assertions in `webhookApi.ts` to satisfy `@typescript-eslint/no-unnecessary-type-assertion` and improve code cleanliness.
