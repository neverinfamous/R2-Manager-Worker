# R2-Manager-Worker v3.5.7

## Highlights

- **Fast & Deterministic Builds**: Migrated the package manager from `npm` to `pnpm` for faster dependency resolution and stricter module boundaries.
- **Supply Chain Security**: Hardened GitHub Actions workflows by pinning all external actions to explicit commit SHAs, preventing upstream supply chain attacks.
- **Dependency Hardening**: Updated all runtime dependencies and applied targeted overrides to transitive CLI dependencies to resolve known vulnerabilities.

## Changed

- **deps**: Migrated project from npm to pnpm to improve speed and consistency.
- **ci**: Pinned GitHub Actions by SHA for tamper-proof CI workflows.
- **docs**: Standardized release notes naming convention and formatting.

## Security

- **deps**: Updated dependencies and applied security patches to eliminate transitive vulnerabilities in Docker builds.
