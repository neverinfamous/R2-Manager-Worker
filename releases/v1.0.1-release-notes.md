# R2-Manager-Worker v1.0.1

## Highlights

- **Local Development Fixed**: Developers can now run both frontend and backend servers locally with automatic authentication bypass and mock data support.

## Changed

- **Localhost Detection**: Updated internal scripts to detect localhost and handle development mode properly.
- **Development Documentation**: Updated README and Wiki with accurate local development instructions.

## Fixed

- **Local Development Environment**: Fixed broken local setup, CORS configuration, and added development TOML config.
- **Authentication Bypass**: Added automatic authentication bypass for localhost requests.
- **Mock Data Support**: Added mock bucket data for local testing without Cloudflare API credentials.
- **Missing ASSETS Binding**: Fixed 500 errors when ASSETS binding is missing in development mode.
