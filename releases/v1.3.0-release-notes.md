# R2-Manager-Worker v1.3.0

## Highlights

- **Multi-Bucket Download**: Select and download multiple buckets in a single operation, enabling disaster recovery and mass migrations.
- **Architectural Simplification**: Removed the D1 database dependency entirely, simplifying deployment by relying purely on Cloudflare Access for authorization.

## Added

- **Multi-Bucket Download**: Download selected buckets as a single timestamped ZIP file, maintaining their hierarchical folder structure.
- **Selection UI Enhancements**: Added a "Select All" button and streamlined the bulk action toolbar.

## Changed

- **D1 Database Removed**: Dropped D1 tracking for bucket ownership. Operations now rely completely on Cloudflare Access (Zero Trust) and direct R2 REST API calls, simplifying deployments.
- **Documentation Updates**: Overhauled codebase documentation and wiki to reflect the removal of database bindings.

## Fixed

- **Workers.dev Subdomain**: Fixed an issue where the subdomain was disabled on every deployment by persisting worker configurations.

## Removed

- **D1 Database Tracking**: Removed operations and bindings tied to D1 tables from the environment.
