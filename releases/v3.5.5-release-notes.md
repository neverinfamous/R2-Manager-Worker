# R2-Manager-Worker v3.5.5

## Highlights

- **Robust Supply Chain Security**: Migrated the package manager from `npm` to `pnpm` for faster, deterministic builds, and pinned all GitHub Actions to their exact SHA digests to prevent unauthorized pipeline tampering.
- **Enhanced Accessibility**: Improved Webhook configuration dialogs to fully comply with W3C standards, ensuring a seamless experience for screen readers and keyboard navigation.

## Changed

- **deps**: Converted project from `npm` to `pnpm` for stricter dependency resolution and faster builds.
- **ci**: Pinned GitHub Actions in `.github/workflows/` to exact SHA digests to secure CI/CD pipelines against upstream compromise.

## Fixed

- **ui**: Resolved `<label>` accessibility issues in Webhook Add and Edit dialogs by implementing semantic `<fieldset>` and `<legend>` grouping, improving screen reader compatibility.
