# R2-Manager-Worker v3.0.0

## Highlights

- **S3 Import [BETA]**: Seamlessly migrate data from Amazon S3 or compatible providers to Cloudflare R2 to realize significant cost savings.
- **Metrics Dashboard**: Monitor R2 usage trends and operational success rates with interactive charts for better capacity planning.
- **Webhooks**: Configure real-time HTTP notifications for file operations to trigger external automations and alerts.
- **Audit Logging**: Track comprehensive individual action histories to fulfill compliance requirements and usage visibility.
- **Client-Side API Caching**: Intelligently cache responses to dramatically improve page load speeds by 50-80% on repeat visits.

## Added

- **Bucket Filter Bar**: Client-side filtering by name, size, and date for quick discovery of specific buckets.
- **Automated Database Migrations**: Smart schema detection with one-click upgrades to maintain database compatibility safely.
- **Bucket Item Count**: Immediate visibility into object counts directly on bucket cards.
- **Centralized Logger Service**: Environment-aware logging abstractions to streamline production debugging.

## Changed

- **UI Refinements**: Relocated List/Grid toggles and softened button colors for improved workflow ergonomics.
- **Persistent View Preferences**: Automatically save grid or list view layouts across browser sessions.
- **Dependency Updates**: Upgraded critical dependencies including Wrangler and Vite for enhanced security and performance.

## Fixed

- **Accessibility**: Added required attributes to form elements to ensure proper screen reader support.
- **Type Safety**: Resolved lingering TypeScript warnings to maintain strict codebase reliability.
- **Cache Invalidation**: Fixed stale cache issues after file mutations for accurate data presentation.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.0.0
```
