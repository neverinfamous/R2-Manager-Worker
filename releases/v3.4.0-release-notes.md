# R2-Manager-Worker v3.4.0

## Highlights

- **Local Uploads [BETA]**: Enable direct client-side bucket uploads to dramatically reduce transfer latency by up to 75%.
- **Node.js 24 LTS Upgrade**: Transitioned the entire stack to the latest LTS runtime to leverage substantial performance and security enhancements.
- **ESLint Suppression Remediation**: Eliminated all eslint-disable comments across the repository to enforce an uncompromising code quality baseline.

## Added

- **Local Uploads Toggle**: Inline bucket configuration to activate optimistic, high-performance uploads dynamically.

## Changed

- **Runtime Baseline**: Enforced Node.js >=24.0.0 through updated engine constraints, Docker images, and GitHub Actions workflows.
- **React 19 Compatibility**: Refactored deprecated form event handlers to align seamlessly with React 19 standards.
- **Dependency Upgrades**: Applied critical updates to Vite plugins, Wrangler, and ESLint for robust ecosystem compatibility.

## Fixed

- **Lifecycle Rules Display**: Corrected an erroneous calculation that previously displayed lifecycle rule maximum ages in seconds rather than days.
- **Hook Dependency Arrays**: Patched multiple React hooks to guarantee proper reference tracking and avoid subtle memory leaks.

## Security

- **Tar Package Override**: Upgraded dependencies to remediate high-severity path traversal and race condition vulnerabilities.
- **Docker Image Integrity**: Acknowledged and documented upstream Alpine curl CVEs to maintain strict transparency in dependency tracking.

## Install

```bash
docker pull writenotenow/r2-bucket-manager:v3.4.0
```
