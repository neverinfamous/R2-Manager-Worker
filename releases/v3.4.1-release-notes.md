# R2 Bucket Manager v3.4.1

## Highlights

- **Relaxed API Rate Limits**: Doubled all rate limit tiers (READ to 600/min, WRITE to 200/min) to reduce 429 errors during normal usage.
- **ESLint 10 Migration**: Upgraded linting toolchain to ESLint 10 with strict checking to ensure code quality.

## Changed

- **Rate Limits**: Doubled all rate limit tiers to reduce 429 errors.
- **ESLint 10**: Upgraded linting toolchain to ESLint 10 with strict checking.
- **Dependencies**: Updated `@cloudflare/workers-types`, `@types/node`, `eslint`, `wrangler`, `react-dropzone` and others to latest versions.

## Fixed

- **Accessibility**: Fixed "No label associated with a form field" violation in the LocalUploadsToggle component by using a span.
- **Code Quality**: Resolved 9 new violations surfaced by ESLint 10, including useless assignments and caught error handling.

## Security

- **tar**: Updated tar override from 7.5.7 to 7.5.8 to address CVE-2026-26960.
- **minimatch**: Patched ReDoS vulnerabilities (GHSA-7r86-cg39-jmmj, GHSA-23c5-xmqv-rm74, CVE-2026-27904, CVE-2026-27903) in npm and Dockerfile.
- **CodeQL**: Removed deprecated inputs from CodeQL workflow.
