# R2-Manager-Worker v3.5.1

## Highlights

- **Dependency Optimization**: Optimized frontend and worker development dependencies to ensure a faster, more reliable build process.
- **Security Enhancements**: Remediated high-severity vulnerabilities in transitive dependencies (`picomatch`, `flatted`), ensuring a secure build environment without breaking lockfile constraints.
- **Improved Stability**: Addressed zero-step sequence hang issues in `brace-expansion`, eliminating build pipeline interruptions.

## Changed

- **deps**: Bumped `esbuild` to 0.28.0, `lucide-react` to 1.7.0, `typescript` to 6.0.2, and `@cloudflare/workers-types` to 4.20260405.1 to leverage the latest features and performance improvements.
- **deps**: Applied minor and patch dependency updates to maintain system currency.

## Fixed

- **build**: Updated `brace-expansion` override to permanently resolve zero-step sequence hang issues that caused pipeline stalls.

## Security

- **deps**: Added layout-agnostic patching for `picomatch` to prevent Method Injection vulnerabilities.
- **deps**: Pinned `flatted` transitive dependency to prevent Prototype Pollution vulnerabilities.
